## Reflection

### What I understood
AI is a broad umbrella, machine learning learns patterns from data instead of hand-written rules, and generative AI creates new content. An agent is a system (model + tools + loop), not a type of model. A language model generates text by repeatedly predicting the next token, so fluent output is not the same as true output. I also learned that a primary source or a test, not the AI's confident tone, is what settles a claim.

### What still confuses me
How attention lets the model read all the tokens in its context together. I also find the line between a tool-using assistant and an agent blurry, since it seems to be a matter of degree.

### One thing I will verify differently next time
I will open the primary source myself before writing the Evidence section, instead of relying on search results that quote the source second-hand.
